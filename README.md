### 🌍 Country Explorer

A dynamic web application that fetches country data from the REST Countries API and displays information such as flags and populations.

**Features:**

* Real-time country search
* Country flags and population display
* Loading indicators
* Error handling
* Responsive design

---

### 🎬 Movie Search Application

An interactive movie search platform integrated with the OMDb API, allowing users to explore movie information dynamically.

**Features:**

* Search movies by title
* View movie details and posters
* Pagination support
* Loading states and error handling
* Mobile-friendly interface
