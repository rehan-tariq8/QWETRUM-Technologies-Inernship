# 🚀 TechFlow – Responsive Landing Page

A modern and responsive landing page developed for **TechFlow**, a fictional technology service platform. This project was completed as part of my **Web Developer Internship at QWETRUM Technologies** to strengthen my skills in frontend development and responsive web design.

---

## 📌 Project Overview

TechFlow is a clean and visually appealing landing page designed to showcase a fictional service through an engaging user experience. The project focuses on creating a fully responsive interface using core web technologies while implementing smooth navigation and modern layout techniques.

---

## 🎯 Project Objectives

* Build a responsive landing page using HTML, CSS, and JavaScript.
* Implement modern layout techniques using Flexbox and Grid.
* Ensure compatibility across desktop, tablet, and mobile devices.
* Create a visually consistent and user-friendly interface.
* Enhance user experience with smooth scrolling and interactive elements.

---

## ✨ Features

### 🧭 Sticky Navigation Bar

* Navigation bar remains fixed at the top while scrolling.
* Provides quick access to different sections of the page.

### 🎉 Hero Section

* Eye-catching headline introducing TechFlow.
* Call-to-action (CTA) button encouraging user interaction.

### 💡 Feature Showcase

* Three feature cards highlighting the key services and benefits offered by TechFlow.
* Clean and organized layout for improved readability.

### 🔗 Smooth Scrolling

* CTA button smoothly scrolls users to the Features section.

### 📱 Responsive Design

* Optimized for:

  * Desktop Devices
  * Tablets
  * Mobile Phones

### 🎨 Modern UI Design

* Consistent color palette and typography.
* Balanced spacing and alignment.
* Interactive hover effects for improved user engagement.

---

## 🛠️ Technologies Used

* **HTML5** – Semantic structure and content organization
* **CSS3** – Styling, animations, Flexbox, Grid, and media queries
* **JavaScript (ES6)** – Smooth scrolling and interactive functionality
