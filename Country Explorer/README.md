# 🌍 Country Explorer

A responsive web application that fetches and displays country information using the **REST Countries API**. Users can browse countries, search by name in real time, and view essential details such as flags and population statistics through an intuitive and mobile-friendly interface.

## 📌 Project Overview

Country Explorer is designed to demonstrate the use of **JavaScript API integration**, **dynamic content rendering**, and **responsive web design**. The application retrieves live country data from a public API and presents it in a visually appealing card-based layout.

## ✨ Features

* 🌐 Fetches country data from the REST Countries API
* 🚩 Displays country flags
* 👥 Shows population information for each country
* 🔍 Real-time search functionality to filter countries by name
* ⏳ Loading spinner while data is being fetched
* ⚠️ Friendly error handling for failed API requests
* 📱 Fully responsive design for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

* **HTML5** – Structure and semantic markup
* **CSS3** – Styling and responsive layouts
* **JavaScript (ES6+)** – API integration and DOM manipulation
* **REST Countries API** – Source of country data

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/country-explorer.git
```

2. Navigate to the project folder:

```bash
cd country-explorer
```

3. Open the `index.html` file in your preferred web browser.

No additional installations or dependencies are required.
